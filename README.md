# KuroKuma Hub

KuroKuma Hub is a web application designed to help manage AI business projects and tasks.

## Current Features

- Project tracker
- Task tracker
- Complete/Undo tasks
- Delete projects and tasks
- Live dashboard statistics
- Data saved using localStorage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git

## Planned Features

- Due dates
- Search
- Progress tracking
- AI assistant
- Revenue dashboard
- User accounts
